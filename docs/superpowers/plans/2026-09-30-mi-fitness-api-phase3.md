## Задачи

### Задача 1: слить маршруты чтения (PR #26)
Дождаться зелёного CI, merge, релиз 1.9.1 вместе с задачами 2-5.

### Задача 2: GET /api/v1/data/coverage
Спека, «REST API»: по каждому типу первая и последняя дата, число дней
(строк), время последнего синка из sync_state. Без параметров. TDD: тест в
tests/api/test_data_api.cpp, красный прогон CI, реализация в
HealthReadRepository + DataController.

### Задача 3: GET /api/v1/data/export
Спека: format ∈ json, csv; фильтры from/to и необязательный type.
JSON: конверт как у моста (schema_version "1.0", source "mi-fitness-api",
generated_at, filters, records по типам). CSV: только с type (плоская
таблица одного типа), text/csv, экранирование значений с ведущими
= + - @ апострофом, как _escape_csv_value моста. Лимит пагинации на
экспорт не действует, но диапазон обязателен.

### Задача 4: probe не мешает синку
Global Constraint: probe и синк не гоняют одновременно (оба логинятся,
логин ротирует токен). XiaomiController::probe при живой строке running в
sync_runs отвечает 409 sync_in_progress без похода в облако. TDD.

### Задача 5: гигиена отложенных minor-ов обзора плана 2
Берутся четыре дешёвых и злых: split_range виснет при chunk_days <= 0
(пол в 1); дубли в data_types отклоняются 400; ответы 503
queue_unavailable/journal_unavailable задокументированы в openapi;
warn-логи синка не несут e.what() ошибок pqxx (тексты сервера — вместо
них имя типа исключения). Остальные minors остаются отложенными.

### Задача 6: вывод Python-моста
Спека, «Переход», п.4. Сверка выполнена (docs/parity-report-2026-09.md).
Шаги: (1) снять финальную копию SQLite с PVC read-only подом и положить
локально вне git-каталогов; (2) удалить namespace mi-fitness целиком
(CronJob, деплоймент MCP, PVC); (3) подтвердить освобождение диска;
(4) заметка в журнале. Удаление необратимо — перед шагом 2 короткое
подтверждение пользователя.

## Review Focus
- Экспорт CSV: формульная инъекция в ячейках (=SUM(...) в строковых полях).
- Coverage на пустой таблице: NULL-даты не превращаются в мусор.
- 409 у probe: не путать с 503 not_configured.
- Export больших диапазонов: без лимита ответ на квартале пульса ~1 МБ JSON — приемлемо, но проверить, что json_agg не упирается в таймаут запроса.
